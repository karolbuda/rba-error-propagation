# RBA error propagation code

All code included in this repository is for the work outlined in "Substrate-dependent epistasis probes active site intramolecular wiring."

`pte-substrate-analysis_v2.Rmd` is an R-markdown file containing data processing for phosphotriesterase kinetic data and the implementation of reference-based analysis (RBA) in R
`pte-substrate-analysis_v2.html` is HTML output from the `.Rmd` file

`CVO061c_Error_propagation_simulation.` is Python notebook that establishes a simulation of epistasis data and analyzes it using a Python-based implementatin of RBA
`CVO061c_Error_propagation_simulation.html` is HTML output from the `.ipynb` file
